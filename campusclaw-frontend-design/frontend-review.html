本轮确认项

1. 是否确认三状态信息架构？

firstUse、idleConversation、runningConversation 作为首版稳定评审和测试边界。

2. 是否确认 Codex-inspired 视觉方向？

黑白中性层级、近黑主动作、少量绿色状态、蓝色仅用于焦点/链接；保留 CampusClaw 自有品牌。

3. 已确认：跟进交互与 Codex desktop 一致

desktop 默认“调整方向”，设置可切换“加入队列”；Cmd/Ctrl+Shift+Enter 对单条消息临时反转。“调整方向”不会硬中断当前模型或工具。

4. 是否确认 Assistant-only 安全富文本边界？

Assistant 正文支持受限 Markdown；User、Thinking 和 Tool 原始结果保持纯文本/专用 viewer。raw HTML、远程 Markdown 图片、相对路由和危险协议永不激活。

5. 本轮方向：思考与工具入参共用活动区

Thinking 在工具附近按时序显示，但仍是独立纯文本 disclosure；工具卡在同一张卡内先显示经 bridge 脱敏的入参，再显示结果，不暴露内部 ID、绝对路径或凭据。
