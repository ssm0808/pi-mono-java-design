作用

提交结构化 name、arguments 和 fileIds；name 不含 Slash。Service 把省略的 arguments 和 fileIds 分别归一为空字符串和空列表，并拒绝未知字段。每次已接受调用生成 command- 加 32 位小写十六进制 UUID，并保存 started 和 completed/failed 生命周期。Skill 或 Compact 接受后，断线不取消执行；调用方从 GET Events 查询结果，不重放 POST。该接口与 POST Events 使用相同的瞬时凭据边界：Header 不校验、不记录、不持久化，只在 Skill 实际调用 Mate Tool 时原名传递。
