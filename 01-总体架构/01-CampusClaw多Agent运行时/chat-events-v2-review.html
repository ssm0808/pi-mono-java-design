CampusClaw Session Events API

2.0.0-proposal.18Internal · 当前评审：查看对话历史 · target-only字段：lowerCamelCaseHeader：保留原名
/campusclaw-service/v1
GET/sessions/{sessionId}/events分页查询与 POST SSE 一致的完整事件查看对话历史listSessionEvents

作用

当前评审 ListEvents；这是目标设计，尚未修改 CampusClaw 实现。保留 GET 历史查询，不恢复 GET /events/stream。普通 JSON 响应使用 ResultBean，result.events 是有序完整事件数组，result.nextPage 是下一页的不透明游标或 null。三类已接受的 user.* 回执与 agent.message、agent.thinking、agent.tool_call、agent.tool_result、session.status_idle 使用 POST SSE 的相同 eventId、createdAt 和业务字段；正文/思考只返回 phase=completed，不返回 delta、心跳或连接结束标记。已确认按已提交内部顺序返回，客户端保持数组顺序，不按 createdAt 重排，不公开 entryId、entrySeq 或执行标识。当前候选以当前分支为首查范围，首次查询固定分支、已提交上界和可见性规则；后续 page 继续同一快照。后来写入的事件需另起第一页读取，nextPage=null 仅表示本快照读完，不表示执行已结束。候选沿用 Session thinking 开关过滤已获准公开的摘要；开关或授权条件变化时不能凭旧 page 继续读取已失去权限的内容。每页重新检查访问边界，page 不是访问凭据。中断回执只表示已接受；相同停止 idle 在历史中只出现一次。等待确认的 idle 不能解除 M1 的 running 状态；不能用某条历史 idle 判定现在可提交 M2。只读接口不要求 access-token，不创建执行凭据、不调用 Mate 工具，所有凭据都不进入历史或游标。未整体确认 ListEvents 或合并 POST；配置变更、压缩、Usage 与其他扩展事件的 v2 映射仍待补齐，不能因基础示例未列出而删除既有能力。CampusClaw 内部 sessionId 不直接暴露给浏览器，Mate 公共 API 不在本轮修改范围。

参数与请求体

位置名称必填约束说明
pathsessionId是^session-[0-9a-fA-F]{32}$已经存在且未删除的内部 Session 标识；不暴露给浏览器
querylimit否integer 1..200; default 100（候选沿用）本页最多返回的完整事件条数，不是消息轮数；用户、工具和状态事件分别计数。第一页/下一页示例使用 2，其他场景使用 100。默认值、上限和跨页修改规则尚未冻结。
querypage否opaque string第一页不传；后续页原样使用上一响应的 nextPage，不能用 eventId 替代。候选绑定 Session、固定分支、已提交上界、上次返回位置、可见性/投影版本、方向及到期时间；字段均封装在游标内，不公开内部序号。
headerAccept-Language否zh-CN | en-US异常消息语言；缺失或不支持时回退 en-US

无请求体。第一页：?limit=2；配对下一页：?limit=2&page=page_h7Qb2Yk9Lm4Np6Rx8Tv3Wa5Zc0De1Fg2Hi3Jk4Lm5No6Pq7Rs8Tu9Vw。该游标是非生产演示值，不能用于调用真实环境。示例暂按旧到新分页，方向待下方选择。
