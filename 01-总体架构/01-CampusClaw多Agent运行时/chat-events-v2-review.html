/campusclaw-service/v1
GET/sessions/{sessionId}/events/stream持续接收 Session 的新事件，不触发执行订阅 Session 实时事件streamSessionEvents

作用

当前评审第二个接口；第一个 POST /events 已确认。本接口只建立指定 Session 的实时订阅，不提交用户事件、不启动或取消执行，也不修改执行凭据。连接可以跨越多次执行与空闲状态，同一 Session 允许多个订阅者。以下为候选：注册订阅完成后先发送 : connected 注释；业务帧只使用 data: JSON，类型放在 type，不发送 SSE event: 或 id:。以与 Mate 同构的五类基础事件展示候选字段，但保留 Claw 的 assistant/tool/session 命名；配置、压缩和子 Agent 投影另行补齐，不视为已删除。收到 session.status.idle 不关闭连接。已确认的 eventId、无公开 entrySeq 及内部依赖顺序继续生效；新的帧格式、事件投影、GET access-token 和 user.* 是否推送仍待本轮确认。

本轮需要你确认

本轮只评审 GET /events/stream，不重新确认 POST。候选保持 Session 长连接、只收新事件、无回放，断线不取消执行。完整事件必须先提交再发布，并保持内部顺序；每条连接独立有界排队，delta 可丢弃，完整事件无法入队时关闭该连接并查历史，不能阻塞模型或其他订阅者。不按 createdAt 重排，也不能用最后一条 createdAt 作为可靠恢复位置。以下推荐项仅用于形成当前示例，不代表用户已确认。
