/mate-service/internal/v1
POST/responses创建前台流式模型响应

作用

接收可直接调用 OpenAI Responses 兼容 LLM 的请求体。Provider 在进入 Mate 前完成 AgentLoop Context 到 Responses JSON 的唯一一次转换；Mate 校验受控子集后只替换 model 值并注入连接层凭据，不转换 input、tools、reasoning 或事件结构。调用只校验服务身份，不接收 agentId；网络结果未知时不得自动重放。

认证

JWT 首选
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司内部调用方标识
Authorization是Bearer <JWT>公司 JWT；不得与 X-HW-APPKEY 同时提供
POST /mate-service/internal/v1/responses
X-HW-ID: <CALLER_ID>
Authorization: Bearer <JWT>
APPKEY 兼容
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司内部调用方标识
X-HW-APPKEY是<APPKEY>公司 APPKEY；不得与 Authorization 同时提供
POST /mate-service/internal/v1/responses
X-HW-ID: <CALLER_ID>
X-HW-APPKEY: <APPKEY>

参数与请求体

位置名称必填约束说明
headerAccept是text/event-stream成功响应固定为 Responses SSE；浏览器 EventSource 不能发起该 POST
headerAccept-Language否zh-CN | en-US仅用于首个 SSE 字节发送前的 ResultBean 错误；缺失或不支持时回退 en-US

OpenAI Responses 语义透明子集。model 为 1-64 字符、大小写敏感的 Mate 目录 ID；input 可为字符串或数组，Provider 对 AgentLoop 始终发送数组。stream、store、background 必须显式为 true、false、false。除把 model 替换为 upstreamModelId 外，Mate 必须原样保留已接受字段的名称、嵌套结构、数组顺序和值；请求可直接发送到原生 Responses 上游，不转换为 Chat Completions 或厂商 DTO。不支持 Idempotency-Key、previous_response_id、conversation、metadata、messages、stream_options、未知字段或任意连接配置。

MateService OpenAI Responses Provider API

1.2.0Internal · 已冻结
/mate-service/internal/v1
POST/responses/{responseId}/cancel取消活动的前台模型响应

作用

使用 response.created 中直接透传的 OpenAI response ID 取消仍处于活动状态的前台流。成功返回原生 Response 对象；Mate 不保存终态，因此已完成、已取消或未知 ID 统一返回 RESPONSE_NOT_ACTIVE。

认证

JWT 首选
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司内部调用方标识
Authorization是Bearer <JWT>公司 JWT；不得与 X-HW-APPKEY 同时提供
POST /mate-service/internal/v1/responses/{responseId}/cancel
X-HW-ID: <CALLER_ID>
Authorization: Bearer <JWT>
APPKEY 兼容
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司内部调用方标识
X-HW-APPKEY是<APPKEY>公司 APPKEY；不得与 Authorization 同时提供
POST /mate-service/internal/v1/responses/{responseId}/cancel
X-HW-ID: <CALLER_ID>
X-HW-APPKEY: <APPKEY>

参数与请求体

位置名称必填约束说明
pathresponseId是non-blank opaque response ID从 response.created.response.id 获取，大小写敏感；调用方只能原样 URL 编码后传回
headerAccept-Language否zh-CN | en-US错误消息语言；缺失或不支持时回退 en-US

无请求体，不提交 model、agentId、sessionId、invocationId 或取消原因。

响应

200 200 OK — 活动响应已取消；原 SSE 直接结束，不发送伪造的 completed 或自定义 cancelled 事件。
