## 复验方法

仓库根目录运行：

```sh
python3 scripts/verify-frontend-design.py
python3 scripts/render-diagram-index.py
git diff --check
```

原型回归需要 Node.js 与 jsdom。本次使用 Node.js 24.14.0、隔离安装的 jsdom 26.1.0；设计仓未增加 npm 安装目录或产品运行依赖。将 `JSDOM_MODULE` 指向已有 jsdom 的绝对路径后运行：

```sh
node 07-前端设计/原型/test_frontend_review.cjs
node 07-前端设计/原型/test_plan_workbench.cjs
node 07-前端设计/原型/test_slash_command_review.cjs
node 07-前端设计/原型/test_token_refresh.cjs
```

启动 README 中的本地 HTTP 预览后，运行 `node 07-前端设计/原型/test_scene_portal.cjs`；默认连接 `127.0.0.1:8765`。可用 `FRONTEND_PREVIEW_URL` 指定另一个本地原型入口。DOM 回归验证状态与动作，页面布局另用真实浏览器检查。
