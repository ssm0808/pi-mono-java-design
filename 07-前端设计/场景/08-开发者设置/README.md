# 08 · 开发者设置

版本：1.0.0 · 2026-09-18

[前端设计](../../README.md) · [公共规范](../../公共规范.md)

在开发环境配置连接、认证和请求头，理解配置何时生效。

**前置条件**：内部 DEV 工作台；生产身份由宿主与公共服务建立。

## 原型

[高保真](../../原型/index.html#scene=settings&fidelity=high) · [低保真](../../原型/index.html#scene=settings&fidelity=low)

状态入口：Headers 与认证助手。高保真检查布局、视觉和可操作性；低保真突出区域、顺序与动作。切换保真度保留当前输入和交互状态。

原型覆盖：当前可操作范围为 Header 增删、启停、校验和模拟 Token 回填。统一设置页、按环境保存、热更新与本地秘密配置仍按工作台目标设计实施。

## 交互行为

| 当前状态 | 动作 / 事件 | 用户可见反馈 | 下一状态 |
|---|---|---|---|
| Header 编辑 | 增行 / 删除 / 启停 | 更新行和有效项计数 | 编辑中 |
| 认证助手 | 填写认证中心 IP 并获取 | 显示处理中，保护期间手动修改 | 等待结果 |
| 等待结果 | 模拟 Token 返回 | 回填对应 Header，保留其他输入 | 已更新 |
| 统一设置目标 | 保存并应用 | 校验环境配置，保存成功后替换快照 | 已保存 |
| 在途操作 | 修改设置 | 后续操作读取新快照 | 旧操作保留原快照 |

## 取舍

按环境保存设置减少重复输入；独立请求快照与本地服务秘密存储控制配置切换的影响范围。

## 验收

- 三个预置为空值；清空后零行保持零行。
- 手动编辑、切换认证 IP 后，迟到回执按版本隔离。
- 真实设置实现需覆盖存储失败、环境隔离、刷新恢复及生产入口隔离。
