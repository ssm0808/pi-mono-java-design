# 07 · 命令与技能

版本：1.1.0 · 2026-10-19

[前端设计](../../README.md) · [公共规范](../../公共规范.md)

在当前会话快速发现命令、填写参数，并理解命令结果如何影响任务。

**前置条件**：清单由服务端按状态提供；消息草稿、命令名称和参数分别管理。

## 原型

[高保真](../../原型/index.html#scene=commands&fidelity=high) · [低保真](../../原型/index.html#scene=commands&fidelity=low)

状态入口：会话内命令、完整命令清单、命令参数、选项单选、运行中命令、临时结果。高保真检查布局、视觉和可操作性；低保真突出区域、顺序与动作。切换保真度保留当前输入和交互状态。

原型覆盖：演示清单过滤、标签选择、文本参数、选项型命令的单选列表、临时结果及问答/计划期间的可用命令。Skill 的真实执行需要对应 Gateway。

## 交互行为

| 当前状态 | 动作 / 事件 | 用户可见反馈 | 下一状态 |
|---|---|---|---|
| 消息编辑 | 首字符输入 / | 打开清单，保存普通草稿 | 命令选择 |
| 命令选择 | 过滤并选中 | 收起清单，显示命令标签与参数区 | 待执行 |
| 命令选择 | 选中 model、thinking、mode 等选项型命令 | 不显示文本框，显示可选值单选列表并默认勾选当前值；当前值不可选时不勾选 | 待执行 |
| 待执行（选项型） | 方向键、Home/End 或点击 | 移动勾选，首尾循环；勾选只改草稿 | 待执行 |
| 待执行（选项型，运行中） | 打开命令 | 可选值禁用且不勾选，提示回车查询当前值 | 待执行 |
| 待执行 | 明确执行 | 冻结命令与参数，防止重复提交 | 执行中 |
| 内置命令完成 | 读取结果 | 在输入附近显示临时结果 | 恢复消息草稿 |
| Skill 已接受 | 接收执行事件 | 进入普通消息、工具和授权流程 | 任务执行中 |

## 取舍

选择与执行分两步降低误触；内置命令使用临时结果区，Skill 复用任务时间线以保持同一执行视图。

## 验收

- 首次 Enter 选中、再次明确 Enter 执行，输入法期间保持输入。
- 切换会话隔离临时结果；退出命令恢复普通草稿。
- 运行中清单遵守服务端能力，未知命令保留可修改文本。
- 选项型命令默认勾选当前值，方向键切换、回车执行；手输的非法值回到当前值；运行中不勾选，执行即查询。
