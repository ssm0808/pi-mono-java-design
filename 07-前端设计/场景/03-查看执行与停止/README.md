# 03 · 查看执行与停止

版本：1.0.0 · 2026-09-18

[前端设计](../../README.md) · [公共规范](../../公共规范.md)

理解当前进展、查看真实工具结果，并在需要时停止任务。

**前置条件**：存在当前执行；实施进度来自显式任务事件，工具和推理保留各自内容。

## 原型

[高保真](../../原型/index.html#scene=execution&fidelity=high) · [低保真](../../原型/index.html#scene=execution&fidelity=low)

状态入口：实施进度、已停止、断线恢复。高保真检查布局、视觉和可操作性；低保真突出区域、顺序与动作。切换保真度保留当前输入和交互状态。

原型覆盖：可展开活动、推进示例任务、停止并模拟回执和终态。结构化工具 viewer 的深层数据降级由技术验收覆盖。

## 交互行为

| 当前状态 | 动作 / 事件 | 用户可见反馈 | 下一状态 |
|---|---|---|---|
| 执行中 | 展开分析 / 工具 | 查看原始推理或输入→输出 | 执行中 |
| 执行中 | 点击输入区停止 | 显示停止中并锁定重复操作 | 等待停止回执 |
| 等待回执 | 停止回执到达 | 继续等待真实执行终态 | 停止中 |
| 停止中 | 实际终态到达 | 保留已完成内容与未完成进度 | 已停止 |
| 连接中断 | 刷新状态 | 补读历史，恢复当前执行 | 执行中 / 终态 / 待确认 |

## 取舍

任务清单、工具结果与执行终态分别表达：清单完成仍可能有收尾工作，停止接受后也可能需要等待实际退出。

## 验收

- 停止、完整回执和实际终态可逐步演示。
- 停止保留新草稿与真实任务状态；工具成功由结果确定。
- 实时与历史使用同一投影，重复记录只显示一次。
