# 02 · 发送消息与附件

版本：1.3.0 · 2026-09-19

[前端设计](../../README.md) · [公共规范](../../公共规范.md)

提交目标与材料，确认请求是否被接收，并继续编辑后续草稿。

**前置条件**：会话空闲且接入能力就绪；公共文本与附件限制按公共 Chat 契约。

## 原型

[高保真](../../原型/index.html#scene=message&fidelity=high) · [低保真](../../原型/index.html#scene=message&fidelity=low)

状态入口：编辑消息、提交结果待确认、断线恢复、发送消息、正在发送、发送失败。高保真检查布局、视觉和可操作性；低保真突出区域、顺序与动作。切换保真度保留当前输入和交互状态。

原型覆盖：附件按钮添加本页示例材料，上传、扫描和 READY 绑定由附件服务实现；当前原型只演示数量限制与回执后的草稿处理。

[发送消息](../../原型/index.html#scene=message&fidelity=high&state=token-ready) · [正在发送](../../原型/index.html#scene=message&fidelity=high&state=token-refreshing) · [发送失败](../../原型/index.html#scene=message&fidelity=high&state=token-failed)

“演示选项”默认折叠，展开后可选择模拟结果、暂停与返回回执。对话区只显示“正在发送…”和必要失败反馈，不展示 Token 刷新阶段或成功提示；失败保留草稿并提供重试。设置面板显示合成 Token 更新，关闭面板不取消发送准备，应用示例配置会取消准备。仅模拟消息路径，不覆盖其他五类动作、真实存储和认证中心。

## 交互行为

| 当前状态 | 动作 / 事件 | 用户可见反馈 | 下一状态 |
|---|---|---|---|
| 空闲 | 输入文本 / 添加附件 | 校验文本、数量与材料状态 | 可提交 |
| 可提交 | 发送 | 冻结输入和目标；统一显示“正在发送…”，后台完成认证 | 准备发送 |
| 准备发送 | DEV Token 获取并保存成功 | 复核目标后发送一次消息；公共 Chat 沿用宿主身份 | 等待回执 |
| 准备发送 | Token 获取失败或配置变化 | 提示消息尚未发送，保留输入，可打开开发者设置修正 | 可重试 / 已取消 |
| 等待回执 | 完整回执到达 | 清除已提交部分，保留随后新增草稿 | 执行中 |
| 结果不确定 | 刷新状态 | 读取历史并核对关联回执 | 已确认 / 仍待确认 |

## 取舍

保留提交时快照与当前编辑草稿，避免回执迟到清空新输入；未知结果通过读取对账。

## 验收

- 公共文本按 2048 Unicode 字符校验，最多 4 个附件。
- 输入法选字和 Shift+Enter 保持输入；回执只清除已提交部分。
- 连接中断后保留内容；重复发送受到状态控制。
- DEV 每次消息先获取 Token，刷新期间消息 POST 为零，成功后恰好一次；刷新失败不退回旧值、不清草稿、不显示运行中。

发送前自动刷新的产品接入待实现；新增原型只验证本地交互，不作为产品集成验收。完整规则与长任务边界见[工作台认证流程](../../技术设计/runtime-workbench-alignment.md#61-页面流程)。
