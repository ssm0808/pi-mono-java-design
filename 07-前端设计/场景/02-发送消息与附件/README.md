# 02 · 发送消息与附件

版本：1.0.0 · 2026-09-18

[前端设计](../../README.md) · [公共规范](../../公共规范.md)

提交目标与材料，确认请求是否被接收，并继续编辑后续草稿。

**前置条件**：会话空闲且接入能力就绪；公共文本与附件限制按公共 Chat 契约。

## 原型

[高保真](../../原型/index.html#scene=message&fidelity=high) · [低保真](../../原型/index.html#scene=message&fidelity=low)

状态入口：编辑消息、提交结果待确认、断线恢复。高保真检查布局、视觉和可操作性；低保真突出区域、顺序与动作。切换保真度保留当前输入和交互状态。

原型覆盖：附件按钮添加本页示例材料，上传、扫描和 READY 绑定由附件服务实现；当前原型只演示数量限制与回执后的草稿处理。

## 交互行为

| 当前状态 | 动作 / 事件 | 用户可见反馈 | 下一状态 |
|---|---|---|---|
| 空闲 | 输入文本 / 添加附件 | 校验文本、数量与材料状态 | 可提交 |
| 可提交 | 发送 | 保留提交快照并显示提交中 | 等待回执 |
| 等待回执 | 完整回执到达 | 清除已提交部分，保留随后新增草稿 | 执行中 |
| 结果不确定 | 刷新状态 | 读取历史并核对关联回执 | 已确认 / 仍待确认 |

## 取舍

保留提交时快照与当前编辑草稿，避免回执迟到清空新输入；未知结果通过读取对账。

## 验收

- 公共文本按 2048 Unicode 字符校验，最多 4 个附件。
- 输入法选字和 Shift+Enter 保持输入；回执只清除已提交部分。
- 连接中断后保留内容；重复发送受到状态控制。
