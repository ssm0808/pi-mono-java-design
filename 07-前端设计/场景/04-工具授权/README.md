# 04 · 工具授权

版本：1.0.0 · 2026-09-18

[前端设计](../../README.md) · [公共规范](../../公共规范.md)

在操作执行前理解影响范围，明确允许或拒绝本次工具调用。

**前置条件**：服务端给出待确认工具及其参数；决定绑定具体调用。

## 原型

[高保真](../../原型/index.html#scene=permission&fidelity=high) · [低保真](../../原型/index.html#scene=permission&fidelity=low)

状态入口：等待确认、决定结果待确认。高保真检查布局、视觉和可操作性；低保真突出区域、顺序与动作。切换保真度保留当前输入和交互状态。

原型覆盖：模拟允许、拒绝、拒绝原因、回执与结果；真实授权和并发消费由服务端保证。

## 交互行为

| 当前状态 | 动作 / 事件 | 用户可见反馈 | 下一状态 |
|---|---|---|---|
| 等待确认 | 阅读工具名称与参数 | 展示本次影响与操作按钮 | 等待确认 |
| 等待确认 | 允许执行 | 冻结决定并锁定按钮 | 提交决定 |
| 等待确认 | 拒绝并提交原因 | 校验选填原因并提交 | 提交决定 |
| 提交决定 | 接受回执 | 显示决定已接受，等待后续结果 | 执行中 |
| 状态已变化 | 刷新状态 | 读取权威结果并撤下旧按钮 | 最新状态 |

## 取舍

计划批准与工具授权分别表达，确保审核整体方案后，用户仍能针对具体有副作用的操作作决定。

## 验收

- 工具展示名与参数易读，输入在上、结果在下。
- 允许操作只携带允许决定；拒绝原因按所接契约校验。
- 回执、工具结果和任务完成可区分，重复点击只有一次提交。
