# 05 · 回答问题

版本：1.0.0 · 2026-09-18

[前端设计](../../README.md) · [公共规范](../../公共规范.md)

逐题澄清目标与约束，完整提交答案后继续原任务。

**前置条件**：收到结构化问题事件；单选、多选、自由文本按题目定义展示。

## 原型

[高保真](../../原型/index.html#scene=question&fidelity=high) · [低保真](../../原型/index.html#scene=question&fidelity=low)

状态入口：Plan 提问、Build 提问。高保真检查布局、视觉和可操作性；低保真突出区域、顺序与动作。切换保真度保留当前输入和交互状态。

原型覆盖：演示逐题导航、整批校验、已回答摘要、草稿隔离、断线及其他端处理。

## 交互行为

| 当前状态 | 动作 / 事件 | 用户可见反馈 | 下一状态 |
|---|---|---|---|
| 待回答 | 选择选项 / 输入补充 | 在当前题保存草稿 | 当前题 |
| 当前题 | 下一步 / 上一步 | 校验当前题并切换，保留各题答案 | 相邻题 |
| 末题 | 提交回答 | 验证整批答案，定位首个错误 | 提交中 / 错误题 |
| 提交中 | 接受回执 | 展示只读答案摘要 | 已回答 |
| 已回答 | 继续执行事件到达 | 恢复原任务和原模式 | 继续执行 |

## 取舍

一次显示一道题降低阅读负担，最后整批提交保持问题组的一致性；导航成本由题号、返回和草稿保留补偿。

## 验收

- 前后切题保留草稿，末题一次提交完整答案。
- 整批错误回到首个无效题并聚焦。
- 接受后可展开全部答案，Plan 问题回答仍停留在原有模式。
