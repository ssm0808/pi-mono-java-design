# 01 · 创建与管理会话

版本：1.0.0 · 2026-09-18

[前端设计](../../README.md) · [公共规范](../../公共规范.md)

进入合适的 Agent 会话，并能快速找到、整理已有任务。

**前置条件**：已有可用 Agent 与访问权限；公共 Agent 目录和 Chat 创建属于接入目标。

## 原型

[高保真](../../原型/index.html#scene=sessions&fidelity=high) · [低保真](../../原型/index.html#scene=sessions&fidelity=low)

状态入口：管理会话、新建会话。高保真检查布局、视觉和可操作性；低保真突出区域、顺序与动作。切换保真度保留当前输入和交互状态。

原型覆盖：演示新会话空态、选择、置顶与原位改名。搜索、删除、Agent 目录及刷新恢复按设计验收，尚未在该原型完整模拟。

## 交互行为

| 当前状态 | 动作 / 事件 | 用户可见反馈 | 下一状态 |
|---|---|---|---|
| 已有会话 | 选择列表项 | 切换当前对话，保留列表顺序 | 所选会话 |
| 新建入口 | 新建会话 | 进入空态，可输入目标 | 空闲 |
| 会话列表 | 置顶 / 取消置顶 | 移动到对应分组，保持活动时间 | 会话列表 |
| 会话列表 | 重命名 | 成功后原位更新；冲突保留草稿 | 会话列表 |
| 会话列表 | 删除并确认 | 成功后移除；当前会话被删除则回到入口 | 列表 / 新会话入口 |

## 取舍

选择和管理动作保持活动排序稳定；只有新建或接受新消息更新活动时间，便于用户形成位置记忆。

## 验收

- 点选、改名、恢复和配置操作均保持最近顺序。
- 置顶可撤回；切换会话隔离普通、问题和命令草稿。
- 删除错误、运行中和不确定结果保留可恢复入口。
