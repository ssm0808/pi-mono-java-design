MateService Model Manager Provider API

2.0.0-proposalInternal · 接口字段待评审
/mate-service/internal/v1
GET/models读取通用 Provider 的全局模型目录

作用

为 pi-mono-java 的 CampusMateProvider 提供不含 Agent 可调用性判断的全局安全模型描述，支持 ETag 条件读取。请求经内部网关到达，不携带应用层身份或凭据。MateService 托管调用的资源模型已经确认，但本 operation 的字段仍是待后续评审的同步候选。

参数与请求体

位置名称必填约束说明
headerIf-None-Match否strong ETag上一次成功目录响应的 ETag；匹配当前 catalog revision 时返回 304
headerAccept-Language否zh-CN | en-US错误消息语言；缺失或不支持时回退 en-US

无请求体；不接受 agentId、providerId、状态筛选或分页参数。

响应

200 200 OK — 返回当前全局安全模型描述，并携带强 ETag。
