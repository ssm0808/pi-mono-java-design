CampusMate 定时任务管理 API

2.1.0Public · 待评审 · 待实现
/mate-service/v1
POST/schedules创建定时任务

作用

当前用户在页面上配置一个定时任务，例如“工作日 08:00 汇总园区设备告警”。Mate 把请求体与用户的 access-token 转发给 Claw，Claw 用 token 查出创建者并检查配额后保存；Mate 不写本地记录，返回把 sessionId 改名为 chatId 的完整任务。创建不立即运行，也不创建 Chat。本接口不定义请求头，前端调用时 Mate 框架已完成 access-token 校验。

参数与请求体

无 path/query/header 业务参数。

字段与 Claw 创建接口相同，Mate 原样转发、不增删。name 必填，去首尾空白后 1..256 个字符，可重名；description 可选，最多 2048 个字符；agentId 必填，只校验格式，不校验 Agent 是否存在或启用；prompt 必填，去首尾空白后非空的纯文本，每次运行作为新会话的首条用户消息；schedule 可选，省略或 null 表示只手动运行，非空时只接受 type=cron、Spring 六字段 expression 和可选 IANA timezone（默认 Asia/Shanghai）；metadata 可选，最多 16 对字符串，键最多 64、值最多 512 个字符。不得传入 chatId、sessionId、userId 或 type、id、status、pausedReason、createdAt、updatedAt、lastRunAt、upcomingRunsAt 等只读字段，未知字段同样拒绝。

{
  "name": "工作日园区告警汇总",
  "agentId": "agent-550e8400e29b41d4a716446655440000",

CampusMate 定时任务管理 API

2.1.0Public · 待评审 · 待实现
/mate-service/v1
GET/schedules读取定时任务列表

作用

页面按名称、Agent 和状态查看当前用户能看到的定时任务，包括接口创建的任务和在自己对话中创建的任务。Mate 把 query 与用户的 access-token 转给 Claw，Claw 查出当前用户后筛选，分页与 total 由 Claw 完成。本接口不定义请求头，前端调用时 Mate 框架已完成 access-token 校验。

参数与请求体

位置名称必填约束说明
querypage否integer, ≥1, default 1普通页码，不是游标；由 Claw 校验，0、负数、非整数或超出支持范围返回 400
querylimit否integer, 1..200, default 50本页最多任务数，越界拒绝，不静默截断；由 Claw 校验
queryname否string, 1..256 after trim按名称包含匹配，大小写敏感，% 和 _ 按字面量；空值拒绝；原样转给 Claw
queryagentId否Agent ID按 Agent 精确匹配；合法但无匹配时返回空页；原样转给 Claw
querystatus否active | paused单值精确匹配，小写；省略时两种都返回；原样转给 Claw

无请求体。筛选条件以 AND 组合；重复参数或未知参数返回 400 SCHEDULE_REQUEST_INVALID。

响应

200 · 列表 200 OK — 每项与创建、详情相同，是把 sessionId 改名为 chatId 的完整任务；接口创建的任务 chatId 为 null，对话中创建的任务为原 Chat。按 updatedAt 从新到旧、id 升序排列。没有更多任务时 nextPage 为 null；超出末页或无匹配返回空数组，不返回 404。total 是当前用户创建且匹配筛选的任务总数，不受分页影响；total 与 nextPage 直接使用 Claw 返回的值。
