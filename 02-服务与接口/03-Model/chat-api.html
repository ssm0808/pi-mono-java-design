CampusMate Chat 接口说明

3.0.0Internal · 已确认目标，输出策略迁移待实现
/mate-service/v1
POST/LLM/chat创建前台流式模型调用

作用

CampusClaw 经内部网关调用 Mate 的统一 Chat 接口。请求不携带应用层身份或凭据，不包含 agentId、sessionId、apiId 或上游连接信息。Mate 成功时返回原始 OpenAI 风格 Chat SSE；CampusClaw Provider 负责 Context 转换和流解析。调用方取消通过关闭请求与 SSE 连接完成，不存在独立取消接口；网络结果未知时不得自动重放。

参数与请求体

位置名称必填约束说明
headerAccept是text/event-stream成功响应固定为流式 SSE；浏览器 EventSource 不能发起该 POST
headerAccept-Language否zh-CN | en-US仅用于 SSE 建立前的 ResultBean 错误；缺失或不支持时回退 en-US

Mate 统一 Chat 请求。model、非空 messages、stream=true 和 stream_options.include_usage=true 必填。messages 只支持 system、user、assistant、tool 文本消息；assistant 可携带 tool_calls 及白名单推理重放字段。tools 只支持 function 的 name、description 和 parameters。tool_choice 可选且仅为 auto/none。输出额度完全由 Mate 的逐模型策略控制；请求不接受 max_output_tokens、max_tokens 或 max_completion_tokens，出现时按未知字段返回 400。temperature 可选且范围 0-2。未知字段返回 400；已定义但目标模型不支持的可选参数允许 Mate 静默忽略。

{
  "model": "managed-coding-model",
  "messages": [
    {
      "role": "system",
      "content": "You are a coding assistant."
    },
    {
      "role": "user",
      "content": "读取 README.md 并总结"
    },
    {
      "role": "assistant",
      "content": null,
      "reasoning_content": "I need to read the file first.",
      "tool_calls": [
        {
          "id": "call_01",
          "type": "function",
          "function": {
            "name": "read_file",
            "arguments": "{\"path\":\"README.md\"}"
          }
        }
      ]
    },
    {
      "role": "tool",
      "tool_call_id": "call_01",
      "content": "README file content"
    }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "read_file",
        "description": "Read a local file",
        "parameters": {
          "type": "object",
          "properties": {
            "path": {
              "type": "string"
            }
          },
          "required": [
            "path"
          ]
        }
      }
    }
  ],
  "tool_choice": "auto",
  "temperature": 0.2,
  "stream": true,
  "stream_options": {
    "include_usage": true
  }
}
