mate-service General Chat Events API

1.4.4Public · 已确认 · target-only
/mate-service/v1
POST/chats/{chatId}/events提交一条用户事件

作用

向指定 Chat 提交一项用户操作：发送消息、中断当前执行，或回复工具调用确认。服务端接收并保存事件后，在 result.event 中返回与历史记录一致的完整用户事件；Agent 的后续输出仍从实时流或历史查询获取。一次请求只接受一个事件；提交 interrupt 后，必须等待 chat.status_idle(reason=terminated) 再发送新消息。POST 响应丢失时应查询权威历史，禁止盲目重放。

认证

JWT 首选
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司调用方身份，非空
access-token是<ACCESS_TOKEN>当前调用上下文访问令牌，非空
Authorization是Bearer <JWT>首选公司 JWT；与 APPKEY 同时存在时使用 JWT，JWT 无效不回退
POST /mate-service/v1/chats/{chatId}/events
X-HW-ID: <CALLER_ID>
access-token: <ACCESS_TOKEN>
Authorization: Bearer <JWT>
APPKEY 兼容
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司调用方身份，非空
access-token是<ACCESS_TOKEN>当前调用上下文访问令牌，非空

参数与请求体

位置名称必填约束说明
pathchatId是string, 1..64, case-sensitive调用方有权访问的公共 Chat 标识；不施加额外正则，不接受内部 sessionId

示例展示用户附上园区巡检记录，请 Agent 梳理异常告警并提出处理建议。一次请求只提交一个 event；也可以提交 user.interrupt 中断当前执行，或以 user.tool_confirmation 回复 Tool 确认。user.message 的 content 长度为 1..5，仅允许 text/file；最多一个 text 且必须位于第一项，text 非空白且最多 2048 Unicode code point；最多四个不重复 file，fileId 匹配 ^[0-9a-f]{32}$。user.interrupt 只有 type。user.tool_confirmation 包含 toolCallId、result=allow|deny；toolCallId 必须原样回传 agent.tool_call.toolCallId，其值直接来自 OpenAI Responses call_id 或 Chat Completions tool_calls[].id，按大小写区分的不透明非空字符串处理，不施加正则。denyMessage 仅 deny 可省略或提供非空白的最多 2048 code point 字符串。已知对象忽略未知字段；未知 type、null 条件字段和批量事件非法。

作用

Authorization是Bearer <JWT>首选公司 JWT；与 APPKEY 同时存在时使用 JWT，JWT 无效不回退

位置名称必填约束说明
pathchatId是string, 1..64, case-sensitive调用方有权访问的公共 Chat 标识；不接受内部 sessionId
querycreatedAtGte否RFC 3339 UTC with exactly 3 millisecond digits, inclusive第一页的可选创建时间下界，例如 2026-09-02T08:30:00.000Z
querylimit否int32, 1..200, default 100每页最大事件数；默认值由 Service 归一化
