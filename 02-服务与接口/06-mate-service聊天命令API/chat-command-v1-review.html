/mate-service/v1
GET/chats/{chatId}/commands列出当前 Chat 的 Builtin 和 Skill 命令查看聊天命令清单listChatCommands

作用

mate-service 先验证登录用户和 Chat 权限，再把 chatId 解析为唯一 sessionId，并调用 CampusClaw。命令清单按当前 Chat/Session 状态动态生成，不是文件系统目录。清单保留暂时不可用的命令，但不暴露 sessionId、Agent/Skill ID、Skill 版本或受管路径。清单获取失败时，交互层保留 Slash 草稿并显示错误。当前 mate-service 尚无 Chat→Runtime bridge，因此本接口是 target-only design。

mate-service Chat Command API

1.0.2Public · 已确认 · target-only字段：lowerCamelCaseHeader：保留原名
/mate-service/v1
POST/chats/{chatId}/command执行 Builtin 或 Skill 命令并流式返回结果执行聊天命令executeChatCommand

作用

交互层提交结构化 name、arguments 和 fileIds；name 不含 Slash。mate-service 验证登录用户和 Chat 权限，解析唯一 Session，并使用内部凭据调用 CampusClaw。它解析内部 SSE，删除 sessionId、entryId、Agent/Skill ID、版本、受管路径和私有快照，再生成公共事件。Service 统一处理省略字段并拒绝未知字段。Skill 或 Compact 接受后，浏览器断线不取消执行；客户端从持久化历史查询结果，不重放 POST。当前 mate-service 尚无 Chat→Runtime bridge，因此本接口是 target-only design。

调用上下文 Header

登录用户 Header 示例
Header必填示例值说明
Authorization是Bearer <USER_ACCESS_TOKEN>mate-service 验证登录用户并建立 Chat 权限上下文；不会原样转发到 CampusClaw
POST /mate-service/v1/chats/{chatId}/command
Authorization: Bearer <USER_ACCESS_TOKEN>

参数与请求体

位置名称必填约束说明
pathchatId是string, 1..128用户有权访问的公共 Chat 标识；mate-service 通过稳定一对一映射解析内部 Session
headerAccept-Language否zh-CN | en-US流建立前 ResultBean 与流内错误消息语言；缺失或不支持时回退 en-US

name 必填，使用命令清单中的小写名称且不含 Slash。arguments 最多 262144 字符。fileIds 最多 32 个，元素唯一并保留顺序。Builtin 不接受附件；Skill 接受普通消息附件。不接受 chatId、sessionId、modelId、thinking、metadata 或 Idempotency-Key。

  "arguments": "分析附件并总结",
  "fileIds": [

  ]
}
