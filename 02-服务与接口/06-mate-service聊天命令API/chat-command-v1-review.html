mate-service Chat Command API 评审页

默认内容用于产品、前端和后端澄清业务行为；这里只展示 GET 清单；公共认证、bridge 和错误映射仍待评审，不代表接口已发布。精确 HTTP、JSON 位于折叠区。

1. 先看触发场景确认用户什么时候会调用这个接口。
2. 再看界面结果确认前端如何展示成功、不可用和失败。
3. 最后核对报文研发按需展开原始字段、Header 和响应。

前后端怎么交互

2. mate-service在目标 bridge 中复用 Runtime 轻量投影公共认证与错误映射另行评审
3. 前端按 input 是否存在展示参数输入命令无匹配时保留草稿，不回退普通消息

HTTP错误码发生场景

401UNAUTHENTICATED用户未登录或访问令牌无效。
403CHAT_ACCESS_DENIED登录用户无权访问该 Chat；不得据此探测内部 Session。
404CHAT_NOT_FOUNDChat 不存在、已删除，或尚未建立有效 Runtime Session 映射。
503COMMAND_CATALOG_UNAVAILABLE暂时无法获取命令清单；UI 保留 Slash 草稿。

input 缺失表示当前只允许无参数、无附件调用；hint 仅供展示，不参与参数校验。

无完整 Agent 快照时，目标清单失败，不返回残缺 Builtin；公共错误映射保留待重审状态。

GET 是观察结果，不保证随后 POST 一定成功；POST 仍需独立解析并在所属事务或锁内复核。

Skill 发现不等于 Skill 执行协议已发布。旧公共 POST SSE 已废止，不属于本次 GET 恢复范围。

mate-service Chat Command API

1.3.0Public · GET 字段已确认，公共边界待评审 · target-only字段：lowerCamelCaseHeader：保留原名
/mate-service/v1
GET/chats/{chatId}/commands查看轻量命令清单（字段投影已确认，公共边界待重审）查看聊天命令清单listChatCommands

作用

GET Descriptor 字段投影已确认，按当前 Runtime 轻量清单同步：必填 name/kind/description，可选 input.hint 与仅为 true 时输出的 input.acceptsFiles；running 隐藏 Compact/Skill，Model/Thinking 仅无参；Help 无参且无 input。固定 Builtin 顺序后追加按 name 排序的 Skill。公共认证、Chat→Session bridge 和错误映射仍为 target-only design，尚未整体确认，不得作为实现依据；旧公共 POST SSE 已废止，不能由本次 GET 投影恢复。

调用上下文 Header

登录用户 Header 示例
Header必填示例值说明
Authorization是Bearer <USER_ACCESS_TOKEN>mate-service 验证登录用户并建立 Chat 权限上下文；不会原样转发到 CampusClaw
GET /mate-service/v1/chats/{chatId}/commands
Authorization: Bearer <USER_ACCESS_TOKEN>

参数与请求体

位置名称必填约束说明
pathchatId是string, 1..128用户有权访问的公共 Chat 标识；mate-service 通过稳定一对一映射解析内部 Session
headerAccept-Language否zh-CN | en-US异常消息语言；缺失或不支持时回退 en-US

无请求体；不接受搜索、强制刷新或内部 Session 参数。
