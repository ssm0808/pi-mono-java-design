作用

作用

仅在 Session 处于 running 时接受一条 FollowUp Message。服务端将其按接收顺序加入当前 active execution 的 FollowUp 队列；只有当前执行不再有工具调用或 Steering Message、原本将自然结束时，才把下一条 FollowUp 投递为新的用户消息并继续执行。成功只表示队列已接受，不创建公共 Run 或 FollowUp 资源；消息实际投递时才作为既有 user.message 写入当前分支并通过原 SSE 流发送。首版固定 one-at-a-time，且 FollowUp 的优先级低于 Steer。

POST/sessions/{session_id}/abort中止 Session 当前执行中止会话执行abortSession

作用
