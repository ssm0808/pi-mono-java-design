/campusclaw-service/v1
POST/agents/{agent_id}/sessions创建 Runtime Session

作用

根据 agent_id 创建一个全新的 Runtime Session。CampusClaw 生成 session_id，从 Agent 发布快照读取 defaultModel 并由 Model Manager 校验，然后完成上下文、Skills、Tools、AgentSession 和持久化初始化。该操作无请求体，不调用模型、不启动执行，也不消耗 token；每次成功 POST 都创建新 Session，默认 thinking=false，表示不启用深度思考。

认证

JWT 首选
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司调用方标识
Authorization是Bearer <JWT>公司 JWT
POST /campusclaw-service/v1/agents/{agent_id}/sessions
X-HW-ID: <CALLER_ID>
Authorization: Bearer <JWT>
APPKEY 兼容
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司调用方标识
X-HW-APPKEY是<APPKEY>公司 APPKEY 凭据
POST /campusclaw-service/v1/agents/{agent_id}/sessions
X-HW-ID: <CALLER_ID>
X-HW-APPKEY: <APPKEY>

参数与请求体

位置名称必填约束说明
pathagent_id是^agent_[0-9A-Za-z]{24}$创建后不可变的 Agent 绑定；区分大小写
headerAccept-Language否zh-CN | en-US错误消息语言；缺失或不支持时回退 en-US

无请求体；不接受 session_id、model_id 或 thinking。

响应

/campusclaw-service/v1
DELETE/sessions/{session_id}删除 Runtime Session

作用

不可逆地结束一个 Runtime Session。服务端先持久化逻辑删除状态和清理任务，使后续 GetSession、提交用户事件和配置写入立即不可见或不可用；存在 active execution 时主动 abort，并在后台清理 Runtime History、内部执行状态和内存资源。永久 tombstone 严格只包含 session_id 和 deleted_at；清理状态、重试信息和 owner 不进入 tombstone，由短期内部清理任务承载。该接口不删除 mate-service 的 Chat 名称、业务元数据或附件，它们仍由 mate-service 负责。

/campusclaw-service/v1
POST/sessions/{session_id}/events提交用户消息并流式返回 Session 执行事件

作用

向既有 Session 提交一个 user.message，持久化用户 MessageEntry，并在同一个 HTTP POST 响应中以 SSE 推送完整成功事件序列。一次用户消息可触发多次模型调用、工具调用和多条 Assistant MessageEntry。已确认 user.message、Assistant 消息三阶段、tool.execution.started/completed、持久化 tool.result、session.status.idle 和 stream.end。三个持久化事件的 SSE event 名称和 data 字段与 GET /events 的事件对象对齐；GET 对象仅额外把 SSE event 名称放入 type 字段。网络断开不取消执行，调用方不得自动重放 POST；应通过同一路径的 GET 从头分页读取持久化事件，并按 entry_id/entry_seq 与本地完整事件去重。

Authorization是Bearer <JWT>公司 JWT
POST /campusclaw-service/v1/sessions/{session_id}/events

Authorization: Bearer <JWT>
APPKEY 兼容
Header必填示例值说明
X-HW-ID是<CALLER_ID>公司调用方标识
X-HW-APPKEY是<APPKEY>公司 APPKEY 凭据

headerAccept-Language否zh-CN | en-US流建立前 JSON 异常和流内异常消息语言；缺失或不支持时回退 en-US

请求 type 固定为 user.message；message 和 file_ids 至少提供一项。message 提供时必须包含非空白字符并保留原始值；file_ids 是由文件服务签发、绑定当前 Session 的不透明标识，最多 32 个、不可重复并保留顺序。不接收 model_id、thinking、metadata、instructions、tool choice、timeout、priority、URL、MIME、文件名、Base64、client_request_id 或 Idempotency-Key；接受时固化 Session 当前 model_id 和深度思考开关。

X-HW-ID: <CALLER_ID>
X-HW-APPKEY: <APPKEY>

参数与请求体

位置名称必填约束说明
pathsession_id是^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$已经存在且未删除的 Session 标识；区分大小写
headerIf-Match是strong ETag最近一次 GET Session 或成功配置变更返回的 ETag；缺失返回 428，不匹配返回 412
headerAccept-Language否zh-CN | en-US异常消息语言；缺失或不支持时回退 en-US

只接受布尔字段 thinking；不接受 level、reasoning_effort、模型参数、客户端 capability 或 Idempotency-Key。

{
  "thinking": true
}
